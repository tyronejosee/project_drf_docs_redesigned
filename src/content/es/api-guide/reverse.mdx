# Retornando URLs

> La característica central que distingue el estilo arquitectónico REST de otros estilos basados en red es su énfasis en una interfaz uniforme entre componentes.
>
> &mdash; Roy Fielding, [Architectural Styles and the Design of Network-based Software Architectures][cite]

Como regla, probablemente es una mejor práctica devolver URIs absolutas desde tus APIs Web, como `http://example.com/foobar`, en lugar de devolver URIs relativas, como `/foobar`.

Las ventajas de hacer esto son:

- Es más explícito.
- Deja menos trabajo para tus clientes de API.
- No hay ambigüedad sobre el significado de la cadena cuando se encuentra en representaciones como JSON que no tienen un tipo URI nativo.
- Facilita hacer cosas como marcar representaciones HTML con hipervínculos.

REST framework proporciona dos funciones de utilidad para hacer más simple retornar URIs absolutas desde tu API Web.

No hay ningún requisito para que las uses, pero si lo haces, la API auto-descriptiva podrá generar hipervínculos automáticamente en su salida, lo que hace que navegar por la API sea mucho más fácil.

## reverse

**Firma:** `reverse(viewname, *args, **kwargs)`

Tiene el mismo comportamiento que [`django.urls.reverse`][reverse], excepto que retorna una URL completamente calificada, usando la solicitud para determinar el host y el puerto.

Debes **incluir la solicitud como argumento de palabra clave** a la función, por ejemplo:

```python
from rest_framework.reverse import reverse
from rest_framework.views import APIView
from django.utils.timezone import now

class APIRootView(APIView):
    def get(self, request):
        year = now().year
        data = {
            ...
            'year-summary-url': reverse('year-summary', args=[year], request=request)
        }
        return Response(data)
```

## reverse_lazy

**Firma:** `reverse_lazy(viewname, *args, **kwargs)`

Tiene el mismo comportamiento que [`django.urls.reverse_lazy`][reverse-lazy], excepto que retorna una URL completamente calificada, usando la solicitud para determinar el host y el puerto.

Al igual que con la función `reverse`, debes **incluir la solicitud como argumento de palabra clave** a la función, por ejemplo:

```python
api_root = reverse_lazy('api-root', request=request)
```
