# Códigos de Estado

> 418 Soy una tetera - Cualquier intento de preparar café con una tetera debería resultar en el código de error "418 Soy una tetera". El cuerpo de entidad resultante PUEDE ser corto y robusto.
>
> &mdash; [RFC 2324][rfc2324], Protocolo de Control de Tetera de Hipertexto

No se recomienda usar códigos de estado desnudos en tus respuestas. REST framework incluye un conjunto de constantes nombradas que puedes usar para hacer tu código más obvio y legible.

```python
from rest_framework import status
from rest_framework.response import Response

def empty_view(self):
    content = {'por favor continúa': 'nada que ver aquí'}
    return Response(content, status=status.HTTP_404_NOT_FOUND)
```

El conjunto completo de códigos de estado HTTP incluidos en el módulo `status` se lista a continuación.

El módulo también incluye un conjunto de funciones de ayuda para probar si un código de estado está en un rango dado.

```python
from rest_framework import status
from rest_framework.test import APITestCase

class ExampleTestCase(APITestCase):
    def test_url_root(self):
        url = reverse('index')
        response = self.client.get(url)
        self.assertTrue(status.is_success(response.status_code))
```

Para más información sobre el uso adecuado de los códigos de estado HTTP, ver [RFC 2616][rfc2616]
y [RFC 6585][rfc6585].

## Informativo - 1xx

Esta clase de código de estado indica una respuesta provisional. No hay códigos de estado 1xx usados en REST framework por defecto.

```python
HTTP_100_CONTINUE
HTTP_101_SWITCHING_PROTOCOLS
HTTP_102_PROCESSING
HTTP_103_EARLY_HINTS
```

## Exitoso - 2xx

Esta clase de código de estado indica que la solicitud del cliente fue recibida exitosamente, entendida y aceptada.

```python
HTTP_200_OK
HTTP_201_CREATED
HTTP_202_ACCEPTED
HTTP_203_NON_AUTHORITATIVE_INFORMATION
HTTP_204_NO_CONTENT
HTTP_205_RESET_CONTENT
HTTP_206_PARTIAL_CONTENT
HTTP_207_MULTI_STATUS
HTTP_208_ALREADY_REPORTED
HTTP_226_IM_USED
```

## Redirección - 3xx

Esta clase de código de estado indica que se necesita tomar acción adicional por parte del agente de usuario para cumplir la solicitud.

```python
HTTP_300_MULTIPLE_CHOICES
HTTP_301_MOVED_PERMANENTLY
HTTP_302_FOUND
HTTP_303_SEE_OTHER
HTTP_304_NOT_MODIFIED
HTTP_305_USE_PROXY
HTTP_306_RESERVED
HTTP_307_TEMPORARY_REDIRECT
HTTP_308_PERMANENT_REDIRECT
```

## Error del Cliente - 4xx

La clase de código de estado 4xx está destinada a casos en los que el cliente parece haber errado. Excepto cuando responde a una solicitud HEAD, el servidor DEBERÍA incluir una entidad que contenga una explicación de la situación de error, y si es una condición temporal o permanente.

```python
HTTP_400_BAD_REQUEST
HTTP_401_UNAUTHORIZED
HTTP_402_PAYMENT_REQUIRED
HTTP_403_FORBIDDEN
HTTP_404_NOT_FOUND
HTTP_405_METHOD_NOT_ALLOWED
HTTP_406_NOT_ACCEPTABLE
HTTP_407_PROXY_AUTHENTICATION_REQUIRED
HTTP_408_REQUEST_TIMEOUT
HTTP_409_CONFLICT
HTTP_410_GONE
HTTP_411_LENGTH_REQUIRED
HTTP_412_PRECONDITION_FAILED
HTTP_413_REQUEST_ENTITY_TOO_LARGE
HTTP_414_REQUEST_URI_TOO_LONG
HTTP_415_UNSUPPORTED_MEDIA_TYPE
HTTP_416_REQUESTED_RANGE_NOT_SATISFIABLE
HTTP_417_EXPECTATION_FAILED
HTTP_421_MISDIRECTED_REQUEST
HTTP_422_UNPROCESSABLE_ENTITY
HTTP_423_LOCKED
HTTP_424_FAILED_DEPENDENCY
HTTP_425_TOO_EARLY
HTTP_426_UPGRADE_REQUIRED
HTTP_428_PRECONDITION_REQUIRED
HTTP_429_TOO_MANY_REQUESTS
HTTP_431_REQUEST_HEADER_FIELDS_TOO_LARGE
HTTP_451_UNAVAILABLE_FOR_LEGAL_REASONS
```

## Error del Servidor - 5xx

Los códigos de estado de respuesta que comienzan con el dígito "5" indican casos en los que el servidor es consciente de que ha errado o es incapaz de realizar la solicitud. Excepto cuando responde a una solicitud HEAD, el servidor DEBERÍA incluir una entidad que contenga una explicación de la situación de error, y si es una condición temporal o permanente.

```python
HTTP_500_INTERNAL_SERVER_ERROR
HTTP_501_NOT_IMPLEMENTED
HTTP_502_BAD_GATEWAY
HTTP_503_SERVICE_UNAVAILABLE
HTTP_504_GATEWAY_TIMEOUT
HTTP_505_HTTP_VERSION_NOT_SUPPORTED
HTTP_506_VARIANT_ALSO_NEGOTIATES
HTTP_507_INSUFFICIENT_STORAGE
HTTP_508_LOOP_DETECTED
HTTP_509_BANDWIDTH_LIMIT_EXCEEDED
HTTP_510_NOT_EXTENDED
HTTP_511_NETWORK_AUTHENTICATION_REQUIRED
```

## Funciones de ayuda

Las siguientes funciones de ayuda están disponibles para identificar la categoría del código de respuesta.

```python
is_informational()  # 1xx
is_success()        # 2xx
is_redirect()       # 3xx
is_client_error()   # 4xx
is_server_error()   # 5xx
```
