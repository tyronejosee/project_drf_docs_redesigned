# Paquetes de Terceros

> Los ecosistemas de software [...] establecen una comunidad que acelera aún más el intercambio de conocimiento, contenido, problemas, experiencia y habilidades.
>
> &mdash; [Jan Bosch][cite].

## Acerca de los Paquetes de Terceros

Los Paquetes de Terceros permiten a los desarrolladores compartir código que extiende la funcionalidad de Django REST framework, para soportar casos de uso adicionales.

**Apoyamos**, **fomentamos** y **favorecemos fuertemente** la creación de Paquetes de Terceros para encapsular nuevo comportamiento en lugar de agregar funcionalidad adicional directamente a Django REST Framework.

Nuestro objetivo es facilitar la creación de paquetes de terceros tanto como sea posible, manteniendo una API central **simple** y **bien mantenida**. Al promover paquetes de terceros, aseguramos que la responsabilidad de un paquete permanezca con su autor. Si un paquete demuestra ser suficientemente popular, siempre puede ser considerado para su inclusión en el framework REST central.

Si tienes una idea para una nueva característica, por favor considera cómo puede ser empaquetada como un Paquete de Terceros. Siempre estamos felices de discutir ideas en la [Lista de Correo][discussion-group].

## Creando un Paquete de Terceros

### Compatibilidad de versiones

A veces, para asegurar que tu código funcione en varias versiones diferentes de Django, Python o bibliotecas de terceros, necesitarás ejecutar código ligeramente diferente dependiendo del entorno. Cualquier código que se bifurque de esta manera debe ser aislado en un módulo `compat.py`, y debe proporcionar una única interfaz común que el resto del código base pueda usar.

Consulta el [compat.py][drf-compat] de Django REST framework como ejemplo.

### Una vez que tu paquete esté disponible

Una vez que tu paquete esté decentemente documentado y disponible en PyPI, podrías querer compartirlo con otros que puedan encontrarlo útil.

#### Agregar a la cuadrícula de Django REST framework

Sugerimos agregar tu paquete a la cuadrícula [REST Framework][rest-framework-grid] en Django Packages.

#### Agregar a la documentación de Django REST framework

Crea un [Pull Request][drf-create-pr] en GitHub, y agregaremos un enlace a él desde la documentación principal de REST framework. Puedes agregar tu paquete bajo **Paquetes de terceros** de la sección de Guía de API que mejor se aplique, como [Autenticación][authentication] o [Permisos][permissions]. También puedes enlazar tu paquete bajo la sección [Paquetes de Terceros][third-party-packages].

#### Anunciar en el grupo de discusión.

También puedes informar a otros sobre tu paquete a través del [grupo de discusión][discussion-group].

## Paquetes de Terceros Existentes

Django REST Framework tiene una comunidad en crecimiento de desarrolladores, paquetes y recursos.

Consulta una cuadrícula que detalla todos los paquetes y ecosistema alrededor de Django REST Framework en [Django Packages][rest-framework-grid].

Para enviar nuevo contenido, [crea un pull request][drf-create-pr].

## Soporte Async

*  [adrf](https://github.com/em1208/adrf) - Soporte async, proporciona Vistas, ViewSets y Serializadores asíncronos.

### Autenticación

* [djangorestframework-digestauth][djangorestframework-digestauth] - Proporciona soporte de Autenticación de Acceso Digest.
* [django-oauth-toolkit][django-oauth-toolkit] - Proporciona soporte OAuth 2.0.
* [djangorestframework-simplejwt][djangorestframework-simplejwt] - Proporciona soporte de Autenticación JSON Web Token.
* [hawkrest][hawkrest] - Proporciona Autorización HTTP Hawk.
* [djangorestframework-httpsignature][djangorestframework-httpsignature] - Proporciona un mecanismo de Autenticación de Firma HTTP fácil de usar.
* [djoser][djoser] - Proporciona un conjunto de vistas para manejar acciones básicas como registro, inicio de sesión, cierre de sesión, restablecimiento de contraseña y activación de cuenta.
* [dj-rest-auth][dj-rest-auth] - Proporciona un conjunto de endpoints de API REST para registro, autenticación (incluyendo autenticación de redes sociales), restablecimiento de contraseña, recuperar y actualizar detalles de usuario, etc.
* [drf-oidc-auth][drf-oidc-auth] - Implementa autenticación de token OpenID Connect para DRF.
* [drfpasswordless][drfpasswordless] - Agrega inicios de sesión y registros sin contraseña (inspirados en Medium, Square Cash) vía correo electrónico y números móviles.
* [django-rest-authemail][django-rest-authemail] - Proporciona una API RESTful para registro y autenticación de usuarios usando direcciones de correo electrónico.
* [dango-pyoidc][django-pyoidc] agrega soporte para autenticación OpenID Connect (OIDC).

### Permisos

* [drf-any-permissions][drf-any-permissions] - Proporciona manejo de permisos alternativo.
* [djangorestframework-composed-permissions][djangorestframework-composed-permissions] - Proporciona una manera simple de definir permisos complejos.
* [rest_condition][rest-condition] - Otra extensión para construir permisos complejos de una manera simple y conveniente.
* [dry-rest-permissions][dry-rest-permissions] - Proporciona una manera simple de definir permisos para acciones de API individuales.
* [drf-access-policy][drf-access-policy] - Permisos declarativos y flexibles inspirados en las políticas IAM de AWS.
* [drf-psq][drf-psq] - Una extensión que da soporte para tener **permission_classes**, **serializer_class**, y **queryset** basados en acción y dependientes de reglas basadas en permisos.

### Serializadores

* [django-rest-framework-mongoengine][django-rest-framework-mongoengine] - Clase Serializer que soporta usar MongoDB como capa de almacenamiento para Django REST framework.
* [djangorestframework-gis][djangorestframework-gis] - Complementos geográficos
* [djangorestframework-hstore][djangorestframework-hstore] - Clase Serializer para soportar el campo de modelo DictionaryField de django-hstore y su característica de modo esquema.
* [djangorestframework-jsonapi][djangorestframework-jsonapi] - Proporciona un analizador, renderizador, serializadores y otras herramientas para ayudar a construir una API que cumpla con la especificación jsonapi.org.
* [html-json-forms][html-json-forms] - Proporciona un algoritmo y serializador para procesar envíos de HTML JSON Form según la especificación (inactiva).
* [django-rest-framework-serializer-extensions][drf-serializer-extensions] -
  Habilita listas negra/blanca de campos, y expansión condicional de serializadores hijos por vista/solicitud.
* [djangorestframework-queryfields][djangorestframework-queryfields] - Mixin de serializador que permite a los clientes controlar qué campos se enviarán en la respuesta de la API.
* [drf-flex-fields][drf-flex-fields] - Serializador que proporciona expansión de campos dinámica y conjuntos de campos dispersos vía parámetros URL.
* [drf-action-serializer][drf-action-serializer] - Serializador que proporciona configuración de campos por acción para usar con ViewSets para evitar tener que escribir múltiples serializadores.
* [djangorestframework-dataclasses][djangorestframework-dataclasses] - Serializador que proporciona generación automática de campos para dataclasses de Python, como lo hace el ModelSerializer incorporado para los modelos.
* [django-restql][django-restql] - Convierte tu API REST en una API tipo GraphQL (permite a los clientes controlar qué campos se enviarán en una respuesta, usa sintaxis tipo GraphQL, soporta lectura y escritura en campos planos y anidados).
* [graphwrap][graphwrap] - Transforma tu API REST en una API GraphQL completamente compatible con solo dos líneas de código. Utiliza [Graphene-Django](https://docs.graphene-python.org/projects/django/en/latest/) para construir dinámicamente, en tiempo de ejecución, un ObjectType GraphQL para cada vista en tu API.

### Serializer fields

* [drf-compound-fields][drf-compound-fields] - Provides "compound" serializer fields, such as lists of simple values.
* [drf-extra-fields][drf-extra-fields] - Provides extra serializer fields.
* [django-versatileimagefield][django-versatileimagefield] - Provides a drop-in replacement for Django's stock `ImageField` that makes it easy to serve images in multiple sizes/renditions from a single field. For DRF-specific implementation docs, [click here][django-versatileimagefield-drf-docs].

### Views

* [django-rest-multiple-models][django-rest-multiple-models] - Provides a generic view (and mixin) for sending multiple serialized models and/or querysets via a single API request.
* [drf-typed-views][drf-typed-views] - Use Python type annotations to validate/deserialize request parameters. Inspired by API Star, Hug and FastAPI.
* [rest-framework-actions][rest-framework-actions] - Provides control over each action in ViewSets. Serializers per action, method.

### Routers

* [drf-nested-routers][drf-nested-routers] - Provides routers and relationship fields for working with nested resources.
* [wq.db.rest][wq.db.rest] - Provides an admin-style model registration API with reasonable default URLs and viewsets.

* [djangorestframework-camel-case][djangorestframework-camel-case] - Provides camel case JSON renderers and parsers.
* [nested-multipart-parser][nested-multipart-parser] - Provides nested parser for http multipart request

### Renderers

* [djangorestframework-csv][djangorestframework-csv] - Provides CSV renderer support.
* [djangorestframework-jsonapi][djangorestframework-jsonapi] - Provides a parser, renderer, serializers, and other tools to help build an API that is compliant with the jsonapi.org spec.
* [drf_ujson2][drf_ujson2] - Implements JSON rendering using the UJSON package.

* [djangorestframework-rapidjson][djangorestframework-rapidjson] - Provides rapidjson support with parser and renderer.

### Filtering

* [djangorestframework-chain][djangorestframework-chain] - Allows arbitrary chaining of both relations and lookup filters.
* [django-url-filter][django-url-filter] - Allows a safe way to filter data via human-friendly URLs. It is a generic library which is not tied to DRF but it provides easy integration with DRF.
* [drf-url-filter][drf-url-filter] is a simple Django app to apply filters on drf `ModelViewSet`'s `Queryset` in a clean, simple and configurable way. It also supports validations on incoming query params and their values.
* [django-rest-framework-guardian2][django-rest-framework-guardian2] - Provides integration with django-guardian, including the `DjangoObjectPermissionsFilter` previously found in DRF.
