# HTML y Formularios

REST framework es adecuado para devolver tanto respuestas estilo API como páginas HTML regulares. Adicionalmente, los serializadores pueden usarse como formularios HTML y renderizarse en plantillas.

## Renderizando HTML

Para devolver respuestas HTML, necesitarás usar `TemplateHTMLRenderer` o `StaticHTMLRenderer`.

La clase `TemplateHTMLRenderer` espera que la respuesta contenga un diccionario de datos de contexto, y renderiza una página HTML basada en una plantilla que debe especificarse ya sea en la vista o en la respuesta.

La clase `StaticHTMLRender` espera que la respuesta contenga una cadena del contenido HTML pre-renderizado.

Debido a que las páginas HTML estáticas típicamente tienen un comportamiento diferente de las respuestas de API, probablemente necesitarás escribir cualquier vista HTML explícitamente, en lugar de confiar en las vistas genéricas incorporadas.

Aquí tienes un ejemplo de una vista que devuelve una lista de instancias de "Profile", renderizadas en una plantilla HTML:

- `views.py`:

```python
from my_project.example.models import Profile
from rest_framework.renderers import TemplateHTMLRenderer
from rest_framework.response import Response
from rest_framework.views import APIView


class ProfileList(APIView):
    renderer_classes = [TemplateHTMLRenderer]
    template_name = 'profile_list.html'

    def get(self, request):
        queryset = Profile.objects.all()
        return Response({'profiles': queryset})
```

- `profile_list.html`:

```html
<html>
  <body>
    <h1>Perfiles</h1>
    <ul>
      {% for profile in profiles %}
      <li>{{ profile.name }}</li>
      {% endfor %}
    </ul>
  </body>
</html>
```

## Renderizando Formularios

Los serializadores pueden renderizarse como formularios usando la etiqueta de plantilla `render_form`, e incluyendo la instancia del serializador como contexto para la plantilla.

La siguiente vista demuestra un ejemplo de uso de un serializador en una plantilla para ver y actualizar una instancia de modelo:

- `views.py`:

```python
from django.shortcuts import get_object_or_404
from my_project.example.models import Profile
from rest_framework.renderers import TemplateHTMLRenderer
from rest_framework.views import APIView


class ProfileDetail(APIView):
    renderer_classes = [TemplateHTMLRenderer]
    template_name = 'profile_detail.html'

    def get(self, request, pk):
        profile = get_object_or_404(Profile, pk=pk)
        serializer = ProfileSerializer(profile)
        return Response({'serializer': serializer, 'profile': profile})

    def post(self, request, pk):
        profile = get_object_or_404(Profile, pk=pk)
        serializer = ProfileSerializer(profile, data=request.data)
        if not serializer.is_valid():
            return Response({'serializer': serializer, 'profile': profile})
        serializer.save()
        return redirect('profile-list')
```

- `profile_detail.html`:

```html
{% load rest_framework %}

<html>
  <body>
    <h1>Perfil - {{ profile.name }}</h1>

    <form action="{% url 'profile-detail' pk=profile.pk %}" method="POST">
      {% csrf_token %} {% render_form serializer %}
      <input type="submit" value="Guardar" />
    </form>
  </body>
</html>
```

### Usando paquetes de plantillas

La etiqueta `render_form` toma un argumento opcional `template_pack`, que especifica qué directorio de plantillas debe usarse para renderizar el formulario y los campos del formulario.

REST framework incluye tres paquetes de plantillas incorporados, todos basados en Bootstrap 3. Los estilos incorporados son `horizontal`, `vertical` e `inline`. El estilo predeterminado es `horizontal`. Para usar cualquiera de estos paquetes de plantillas, también querrás incluir el CSS de Bootstrap 3.

El siguiente HTML enlazará a una versión alojada en CDN del CSS de Bootstrap 3:

```html
<head>
  …
  <link
    rel="stylesheet"
    href="https://maxcdn.bootstrapcdn.com/bootstrap/3.3.5/css/bootstrap.min.css"
  />
</head>
```

Los paquetes de terceros pueden incluir paquetes de plantillas alternativos, agrupando un directorio de plantillas que contenga las plantillas de formulario y campo necesarias.

Echemos un vistazo a cómo renderizar cada uno de los tres paquetes de plantillas disponibles. Para estos ejemplos, usaremos una sola clase de serializador para presentar un formulario de "Inicio de sesión".

```python
class LoginSerializer(serializers.Serializer):
    email = serializers.EmailField(
        max_length=100,
        style={'placeholder': 'Correo electrónico', 'autofocus': True}
    )
    password = serializers.CharField(
        max_length=100,
        style={'input_type': 'password', 'placeholder': 'Contraseña'}
    )
    remember_me = serializers.BooleanField()
```

---

#### `rest_framework/vertical`

Presenta etiquetas de formulario encima de sus entradas de control correspondientes, usando el diseño estándar de Bootstrap.

_Este es el paquete de plantillas predeterminado._

```html
{% load rest_framework %} ...

<form action="{% url 'login' %}" method="post" novalidate>
  {% csrf_token %} {% render_form serializer
  template_pack='rest_framework/vertical' %}
  <button type="submit" class="btn btn-default">Iniciar sesión</button>
</form>
```

![Ejemplo de formulario vertical](../img/vertical.png)

---

#### `rest_framework/horizontal`

Presenta etiquetas y controles uno al lado del otro, usando una división de columnas 2/10.

_Este es el estilo de formulario usado en las renderizaciones de la API navegable y de administración._

```html
{% load rest_framework %} ...

<form
  class="form-horizontal"
  action="{% url 'login' %}"
  method="post"
  novalidate
>
  {% csrf_token %} {% render_form serializer %}
  <div class="form-group">
    <div class="col-sm-offset-2 col-sm-10">
      <button type="submit" class="btn btn-default">Iniciar sesión</button>
    </div>
  </div>
</form>
```

![Ejemplo de formulario horizontal](../img/horizontal.png)

---

#### `rest_framework/inline`

Un estilo de formulario compacto que presenta todos los controles en línea.

```html
{% load rest_framework %} ...

<form class="form-inline" action="{% url 'login' %}" method="post" novalidate>
  {% csrf_token %} {% render_form serializer
  template_pack='rest_framework/inline' %}
  <button type="submit" class="btn btn-default">Iniciar sesión</button>
</form>
```

![Ejemplo de formulario en línea](../img/inline.png)

## Estilos de campo

Los campos del serializador pueden tener su estilo de renderizado personalizado usando el argumento de palabra clave `style`. Este argumento es un diccionario de opciones que controlan la plantilla y el diseño utilizados.

La forma más común de personalizar el estilo del campo es usar el argumento de palabra clave de estilo `base_template` para seleccionar qué plantilla en el paquete de plantillas debe usarse.

Por ejemplo, para renderizar un `CharField` como un textarea HTML en lugar de la entrada HTML predeterminada, usarías algo así:

```python
details = serializers.CharField(
    max_length=1000,
    style={'base_template': 'textarea.html'}
)
```

Si en su lugar quieres que un campo se renderice usando una plantilla personalizada que _no es parte de un paquete de plantillas incluido_, puedes usar la opción de estilo `template` para especificar completamente un nombre de plantilla:

```python
details = serializers.CharField(
    max_length=1000,
    style={'template': 'my-field-templates/custom-input.html'}
)
```

Las plantillas de campo también pueden usar propiedades de estilo adicionales, dependiendo de su tipo. Por ejemplo, la plantilla `textarea.html` también acepta una propiedad `rows` que puede usarse para afectar el tamaño del control.

```python
details = serializers.CharField(
    max_length=1000,
    style={'base_template': 'textarea.html', 'rows': 10}
)
```
